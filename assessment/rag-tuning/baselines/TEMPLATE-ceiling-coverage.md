## 0. 怎么用

**基底批次**：`2026-guoqing-self-drive-plan-20260907`（全量内容默认取它）

你只需要在 §1 的表里写「要改的那几格」。**留空 = 采用基底原样。**

### 改用列（4 种写法）

第 1 行是**范围**（你要改哪一格），第 2 行是**改用**（这一格换成什么）。**范围留空 = 整目标接管。**

```text
① 整格替换（默认）：      改写列 = 批次 - 类型 - 目标 - 部分
② 只取来源的某些条：      改写列 = 批次 - 类型 - 目标 - 部分 #1,3
③ 把来源的条并进基底：    改写列 = 合并 批次 - 类型 - 目标 - 部分 #1     ← 基底条目在前，来源条目追加在后
④ 整目标接管：            范围列留空，改写列 = 接管 批次 - 类型 - 目标
```

例：

```text
20260918 - 城市 - 昭通 - 备选景点库                 ① 整格换成 0918 的版本
替换 20260905 - 景点 - 九洞天景区 - 门票            ① 前缀可省略；替换/覆盖 是同义词
合并 20260918 - 景点 - 威宁百草坪 - 推荐游玩线路 #1   ③ 基底 2 条 + 0918 第 1 条
20260918 - 景点 - 兴文石海 - 看点 #1,3              ② 只取 0918 该格的第 1、3 条
接管 20260918 - 城市 - 盐津                        ④ 盐津所有内容字段取自 0918
```

- **批次**：`20260829` `20260831` `20260902` `20260902-2` `20260905` `20260907` `20260918` `20260918-2` `20260918-3`
  （`20260918-2` 无 facts 产物，点到会报错）
- **类型**：`景点` / `城市` / `天` / `全局`（整目标接管只支持 `景点` / `城市`）
- **目标**：中文名；天层写 `day-01` 或 `第1天` 或 `1`；全局层写 `-`
- **部分**：中文名或键名都行（对照见 §2）；口语写法也能认（`门票与优惠` → `门票`、`推荐游玩线路` → `路线`、`不同玩法/游玩方式` → `玩法选项`）
- **条号**：`#1` `#1,3` `#2-4`，1-based，按来源批次该格的原始顺序；越界会直接报错
- **删除某格**：改用列写 `删除`（范围列要写明部分）
- **分隔符**：`-` `·` `|` `｜` `/` `>` 都行，前后空格忽略

### 备注列

可以写自然语言，例：「保留价格，删掉小程序那条」。
无法执行的备注 agent **必须回问**，不会自己替你取舍。
